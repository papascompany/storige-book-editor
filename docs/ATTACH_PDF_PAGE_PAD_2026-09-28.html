첨부 PDF 빈 페이지 채움 padToPageStep

고객이 첨부한 내지 PDF 쪽수가 상품의 증감 단위(pageStep) 배수가 아니면, 첨부 시점에 끝에 빈 페이지를 붙여 배수로 맞춥니다. 템플릿셋별로 켜는 설정이며 기본값은 꺼짐입니다.

목표 쪽수 = ceil(원본 쪽수 ÷ pageStep) × pageStep. 원본 파일은 그대로 두고 채움본을 새 파일로 만듭니다.

왜 첨부 시점인가

완료 시점에 파일 교체 채택 안 함

  • 파트너는 첨부 이벤트에서 받은 contentPdfFileId를 보관해 합성에 직접 넘깁니다. 완료 후 세션 파일을 바꿔도 파트너가 가진 id는 원본 그대로입니다.
  • 완료 직후 합성 요청과 파일 교체 사이에 경합이 생깁니다.

첨부 시점에 채움본 생성 채택

  • 세션, 첨부 이벤트, 편집 화면 내지 수, 합성이 처음부터 같은 파일과 쪽수를 봅니다.
  • worker의 기존 fix-pagecount를 재사용해 worker 수정·배포가 없습니다.
  • 원본 파일은 보존되고, 세션 검증 결과에 pagePadded 마커가 남습니다.

관리자 설정 방법

  1. admin → 템플릿셋 편집 → 탭 2 · 페이지에서 내지 추가 허용을 켭니다.
  2. 페이지 증감 단위에 배수를 입력합니다 (예: 2 = 짝수만, 4 = 4쪽 단위).
  3. 첨부 PDF 빈 페이지 채움 스위치를 채움으로 바꾸고 저장합니다.

증감 단위를 비워 두면 채움 스위치는 동작하지 않습니다. 설정을 켜기 전에 이미 첨부된 세션에는 적용되지 않습니다.
