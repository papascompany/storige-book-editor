# 인쇄 템플릿 용어 정본

> 2026-08-13. Admin·제작 가이드·코드 주석의 한글 이름은 이 문서를 따른다.
> 식별자(`conversionMode`, `regionScope` …)는 바꾸지 않는다. **이름만** 바로잡는다.

세 층을 섞지 않는다.

1. **칸** — 이 템플릿이 표지인가 내지인가 (`regionScope`)
2. **표지 구조** — 책등이 고정인가, 구역이 나뉘어 책등만 늘어나는가 (`conversionMode`)
3. **상품 속성** — 기성·페브릭 잠금, 싸바리, 무선/양장 (`coverEditable`, `coverType`, 제본)

---

## 운영자가 쓰는 이름

| 정본 이름 | 뜻 | 쓰는 상품 | 코드 |
|---|---|---|---|
| **표지펼침면** | 앞·책등·뒤가 **한 장의 고정 폭** 원고. 내지 수가 늘어도 책등 파일을 키우지 않는다. | 포토북 하드커버, 페브릭, 기성 커버 | `regionScope=cover` + `conversionMode=flat-spread` |
| **표지3분할** | 뒷표지 / 책등 / 앞표지 (+날개). 내지 수량에 따라 **책등 구역(파일)만** 폭이 변하고 앞·뒤 면 폭은 그대로다. | 무선·중철 등 페이지 가변 책자 | `regionScope=cover` + `conversionMode=full`(벡터) 또는 `flat-spine`(래스터 3장) |
| **내지낱장** | 캔버스 1장 = 인쇄 1페이지. 내지 1, 내지 2는 서로 다른 시드일 수 있다. | 일반 책자 | `TemplateType.page` |
| **내지펼침면** | 캔버스 1장 = 좌면+우면(물리 2페이지). 상품이 펼침 편집이면 디자이너가 이 템플릿을 만든다. | 포토북·화보집·압축앨범 등 | `regionScope=inner` + `innerSpec` |
| **기성·페브릭 표지** | 표지펼침면 위에 소재를 배경으로 깔고, 고객은 배경을 못 바꾼다. 후가공만 허용할 수 있다. | 페브릭·기성 | `coverEditable=false` + (보통) 표지펼침면 |

**쓰지 말 것**

| 혼용어 | 왜 틀린가 |
|---|---|
| “스프레드”만으로 표지/내지/고정/가변을 가리키기 | `type=spread` 는 **칸이 여러 면인 캔버스**일 뿐. 표지펼침면·표지3분할·내지펼침면을 구분하지 못한다. |
| “표지 스프레드 = 책등 가변” | 표지펼침면은 책등 **고정**이다. |
| “하드커버 = 책등 고정 / 소프트커버 = 책등 가변” | 제본이 아니라 **표지 구조**가 고정·가변을 정한다. 양장도 페이지가 변하면 물리 책등은 변한다. 템플릿이 표지펼침면이면 편집기는 책등을 키우지 않는다. |
| “포토북만 내지펼침면” | 내지 단위는 상품이 고른다. 타입 `PHOTOBOOK` 은 분류 라벨이다. |
| “레더커버” | 폐기. 기성·페브릭 + 소재 잠금. |

## 표지 두 구조 (인쇄 관점)

```
표지펼침면 (책등 고정)          표지3분할 (책등 가변)
┌────┬──┬────┐                 ┌────┐┌──┐┌────┐
│ 뒤 │등│ 앞 │  통짜 1장        │ 뒤 ││등││ 앞 │  (+날개 가능)
└────┴──┴────┘                 └────┘└──┘└────┘
 등 폭 = 템플릿에 박힘            등 폭만 내지 수에 따라 증감
 앞·뒤와 등이 한 그림             앞·뒤 면 폭 불변, 등 파일만 조정
```

- 표지펼침면: 통짜 아트워크라 책등만 늘리면 그림이 깨진다. 시스템이 `resizeSpine` 을 막는다.
- 표지3분할: 객체(또는 PNG)가 뒷/등/앞 구역에 붙는다. 등이 넓어지면 앞·뒤가 바깥으로 밀리고, 등 구역의 그림·텍스트만 폭을 따른다.

IDML 변환 모드는 **원고를 어떻게 넣는지**이지 상품 이름이 아니다.

| 변환 | conversionMode | 정본 이름 |
|---|---|---|
| 벡터 구역 | `full` | 표지3분할 |
| 래스터 3장 (뒤/등/앞 PNG) | `flat-spine` | 표지3분할 |
| 전폭 PNG 1장 | `flat-spread` | 표지펼침면 |

수기 저작(Admin 템플릿 편집)은 `full` 또는 `flat-spread` 만 고른다. `flat-spine` 은 IDML 변환기 전용이다.

## 내지

디자이너가 **상품에 따라** 고른다. 세트 타입이 강제하지 않는다.

| | 내지낱장 | 내지펼침면 |
|---|---|---|
| 캔버스 | 1장 = 1페이지 | 1장 = 좌+우 |
| 시드 | 내지 1, 내지 2 … 페이지 템플릿 | 펼침면 템플릿 1장 이상 |
| 페이지 가산 | +1p | +2p |
| 책등 계산(표지3분할일 때) | 캔버스 수 = 물리 페이지 | 캔버스 수 × 2 = 물리 페이지 |

표지 칸과 내지 칸은 독립이다. 표지펼침면+내지낱장, 표지펼침면+내지펼침면, 표지3분할+내지낱장, 표지 없음+내지펼침면 모두 같은 조립이다. (세트 저장 규칙이 아직 스프레드 1개로 묶여 있으면 그건 **용어가 아니라 조립 규칙 갭**이다.)

## 코드 식별자 (이름 바꾸지 말 것)

| 필드 | 의미 | 한글 이름과 혼동 금지 |
|---|---|---|
| `TemplateType.spread` | 여러 면이 한 캔버스 | “표지펼침면”이 아님 |
| `regionScope` `cover` / `inner` | 표지 칸 / 내지 칸 | 책등 고정·가변이 아님 |
| `conversionMode` | 표지 구조·변환 | 제본 종류가 아님 |
| `coverType` | SKU 시드 (`hardcover_wrap` …) | 템플릿 기하가 아님 |
| `coverEditable` | 고객이 소재를 바꾸나 | 표지 유무가 아님 |
| `editorMode` | 레거시 전역 스위치 | 조립 정본이 아님 |
| `TemplateSetType` | 분류·가격 라벨 | 내지 단위가 아님 |

## 잘못된 문장을 고치는 법

- “스프레드 템플릿” → 칸을 밝혀 **표지펼침면 / 표지3분할 / 내지펼침면**
- “책등 가변 표지 스프레드” → **표지3분할**
- “책등 고정 펼침면” → **표지펼침면**
- “포토북 내지 2-up” → **내지펼침면** (상품 예시는 뒤에)
- “레더커버” → **기성·페브릭 표지**
