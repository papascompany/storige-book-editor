## 2. 새 세트로 편집할 때 — bookmoa · printy

- **편집 화면**: 표지 화면에 완성 면 바깥 사방 20mm 싸바리 여분이 가이드로 표시됩니다. 내지 화면은 같습니다.
- **표지 PDF**: 싸바리 전개 규격으로 만들어집니다.
  - 폭 = (판형 폭 + 8) × 2 + 책등 + 40, 높이 = (판형 높이 + 8) + 40(mm)
  - 210×210mm·책등 8mm → **484×258mm**(= 218×2 + 8 + 40, 218 + 40). 재단 마커·별도 도련은 없습니다(사방 20mm 여분이 그 역할).
- **내지 PDF**: 420×210mm 펼침 2-up 그대로입니다.
- **`metadata.coverOutput`**: 아래 키가 추가됩니다(ADDITIVE). 기존 `widthMm`·`heightMm`·`bleedMm` 은 그대로 실제 PDF 페이지 크기입니다.

```json
{ "widthMm": 484, "heightMm": 258, "bleedMm": 0,
  "layout": "hardcover-wrap", "trimWidthMm": 210, "trimHeightMm": 210, "wrapMm": 20 }
```

- **`editor.complete`·`editor.pricingChange` 의 `spineWidthMm`**: `8` 입니다(적용 책등 폭, 표지 총폭이 아님). 현행 세트에서는 `1.2` 였습니다. 귀사가 `spineWidthMm` 를 보내지 않는 지금 진입 방식 기준입니다.
- **편집 완료 표지 검증**:

| 진입 `bindingType` | 현행 `207c458f` | 새 세트 |
|---|---|---|
| `hardcover` | 표지 크기 검사 생략 | **싸바리 전개 기준 검사** — 기대 484×258mm, 허용 ±2mm |
| 미전달 | 펼침 기준 검사(2W + 책등) | **싸바리 전개 기준 검사** — 위와 같음 |
| 그 밖의 제본값(예: `perfect`) | 펼침 기준 검사(2W + 책등) | 표지 크기 검사 생략 |

  - 편집기가 만든 표지는 기대 규격과 같으므로 정상 편집에서는 오류가 나지 않습니다.
  - 규격이 맞지 않으면 표지 검증 작업이 `FAILED` 가 되고 결과에 `SPINE_SIZE_MISMATCH`('표지 크기가 싸바리 전개 규격과 맞지 않습니다', `details.expected.layout:'hardcover-wrap'`)가 기록됩니다. 이 검증 작업은 세션 `workerStatus` 를 바꾸지 않고 `session.*` 를 보내지 않습니다. 결과는 작업 조회와 `validation.*`(사이트 웹훅 v2 구독 시)로 확인합니다.
  - 편집기가 기록한 표지 규격이 싸바리 전개식과 맞지 않는 세션은 오탐을 막기 위해 표지 크기 검사를 생략합니다.

## 3. 적용 범위 — 기존 세션·주문

- 매핑을 바꾼 뒤 **새로 시작한 편집**만 새 세트로 열립니다.
- 매핑을 바꾸기 전에 만든 세션·장바구니·주문은 `207c458f` 로 계속 열리고, 표지 PDF 도 496×276mm 그대로입니다.
- **재편집(`sessionId`) 주의**: `/embed` 는 URL·props 의 `templateSetId` 를 세션에 기록된 값보다 먼저 씁니다. 기존 세션을 다시 열 때는 `templateSetId` 를 **그 세션의 원래 값(`207c458f`)으로 보내거나 생략**해 주세요. 상품 매핑의 새 id 를 함께 보내면 기존 세션이 새 세트 규격으로 열립니다.

## 4. 전환 절차

1. 귀사 ACK → 귀사 인쇄 공정 확인(§5) → 귀사가 전환 시각(UTC)을 통지.
2. 전환 시각에 귀사가 동화책 상품의 템플릿셋 매핑을 `9e768d01-f2f7-4a1e-a1f6-f1ff45cb2fcb` 로 변경.
3. 같은 시각에 Storige 가 그 상품의 Storige 쪽 템플릿셋 연결을 바꿉니다(관리자 「템플릿셋 조회」에 보이는 연결): 새 세트 연결 추가(기본) → 새 세트 활성 표시(첫 전환 때 1회) → 기존 `207c458f` 연결 비활성 → 결과 확인. 기존 `207c458f` 연결은 기본 해제가 아니라 **비활성**으로 바꿉니다(bookmoa 회신 반영). 세트 `207c458f` 자체는 삭제하거나 비활성으로 바꾸지 않습니다. 전환 시각 전에는 이 연결을 바꾸지 않습니다.
4. 전환 뒤 첫 새 세트 세션을 Storige 가 확인해 회신합니다: 책등 8mm 고정, `coverOutput.layout:'hardcover-wrap'`·484×258mm, 표지 검증 작업 상태(`COMPLETED`, `SPINE_SIZE_MISMATCH` 없음).

- printy 는 매핑을 바꾸기 전까지 영향이 없습니다. bookmoa 와 같은 시각에 바꿀 필요는 없으며, printy 가 전환을 정하면 같은 절차로 따로 진행합니다.

## 5. 요청

- 수신 확인(ACK)을 부탁드립니다. 회신을 받은 뒤 귀사와 전환합니다.
- **전환 시각(UTC)** 은 아래 인쇄 공정 확인이 끝난 뒤 알려 주세요. 파트너별로 따로 정하며, 확인 전에는 Storige 도 연결을 바꾸지 않습니다.
- **인쇄 공정 확인**: 동화책 하드커버 표지를 **484×258mm 싸바리 전개 PDF**(판형 210×210, 한 면 218×218, 책등 8, 사방 여분 20mm, 재단 마커 없음)로 받아 그대로 제작할 수 있는지 인쇄팀 확인을 부탁드립니다.
- **재편집 URL 확인**: 기존 세션을 다시 열 때 `templateSetId` 를 무엇으로 보내는지 알려 주세요(§3).
- **printy**: 동화책 상품의 `/embed` 진입 `bindingType` 값을 알려 주세요. `hardcover` 가 아니면 새 세트의 완료 표지 검증은 표지 크기 검사를 생략합니다(§2).

## 6. 되돌릴 경우

- 귀사가 상품 매핑을 `207c458f` 로 되돌리고, Storige 가 같은 시각에 §4-3 의 연결을 원래대로 돌립니다. 되돌린 시각부터 새로 시작하는 편집은 `207c458f` 로 열립니다.
- 새 세트로 이미 만든 세션은 새 세트(`9e768d01`)로 계속 열립니다. 이 세션이 있으면 새 세트를 삭제하지 않습니다.
- Storige 가 편집기를 2026-10-05 배포 이전으로 되돌려야 하면, 먼저 귀사에 매핑 원복을 요청하고 원복을 확인한 뒤 되돌립니다. 되돌릴 때는 시각과 범위를 바로 통지합니다.
