재단선 포함 PDF · TrimBox 처리

인쇄용 PDF 는 종이 전체 크기(MediaBox) 안에 실제로 잘릴 크기(TrimBox)와 여분 인쇄 영역(BleedBox)을 따로 적습니다. 09-30 전까지 worker 는 MediaBox 만 보고 판형을 판정해서, 재단선이 포함된 정상 파일을 크기 불일치로 거부했습니다. 09-30 부터 TrimBox 기준으로 판정하고, 10-03 부터는 합성 내지를 주문 재단 + 도련 크기로 정리합니다.

실측 파일 B · 박스 구조 (실제 비율, 1mm = 1단위)

MediaBox · 종이 전체 BleedBox · 여분 인쇄 TrimBox · 재단 크기 재단선(crop marks)

09-30 전후 판정

09-30 이전 · MediaBox 236×323 을 기대 판형 210×297(또는 bleed 포함 212×299)과 비교 → SIZE_MISMATCH 로 거부. 파트너에는 session.failed 계열로 전달됩니다.
09-30 이후 · TrimBox 가 파일에 명시돼 있고 MediaBox 보다 작으면 TrimBox 210×297 을 기대 판형과 비교 → 통과. 합성할 때는 재단선 영역을 잘라 TrimBox + 주문 bleed 크기로 맞춥니다.

원본 PDF 는 재단선 영역을 포함한 채 보존됩니다. 원본을 그대로 인쇄 입력으로 쓰는 흐름(첨부 원본 직접 사용)은 인쇄소 RIP 의 TrimBox 처리에 맡기며, 원본 정규화 사본 등록은 후속 과제입니다.

pdf-lib 의 getTrimBox() 는 TrimBox 가 없으면 MediaBox 를 대신 돌려줍니다. 그래서 판별은 페이지 사전에 /TrimBox 가 실제로 있는지로 합니다. MediaBox 만 있는 PDF(100p 등)는 새 경로에 들어가지 않습니다.

판정·처리 흐름

1
기존 판정 먼저 — 내지(fileType=content)만 대상입니다. 지금처럼 MediaBox 로 판정하고, SIZE_MISMATCH 일 때만 다음 단계로 갑니다. 그래서 MediaBox 판정으로 통과하는 파일의 판정 결과는 바뀌지 않습니다(합성 산출 크기는 5단계). 표지·후가공 판은 이번 범위가 아닙니다.
2
TrimBox 명시 여부 (표준 pdf-lib · 경량 qpdf 가 같은 순수 함수로 판정)
없음 · MediaBox 와 같음
지금과 똑같이 MediaBox 로 판정. 결과(isValid·errors·warnings) 불변.
모든 페이지에 있음 · MediaBox 안에 있음
TrimBox 크기로 3단계 진행. 페이지 회전 90°/270°, UserUnit≠1, 페이지 정보 불완전이면 적용하지 않습니다.
3
판형 비교 — 모든 페이지의 TrimBox 를 기대 재단 크기와 허용 오차 1mm 로 비교합니다. 가로·세로를 바꿔 맞추지는 않습니다.
일치 → 판형 통과. 비차단 경고 TRIMBOX_SIZE_BASIS 를 추가하고 metadata.trimBox 를 채웁니다(모두 추가 필드).
불일치 → 기존 SIZE_MISMATCH 그대로(메시지·details.actual 불변). details.trimBox 만 추가.
4
bleed 판정 — 모든 페이지·모든 변에서 BleedBox − TrimBox 의 최소값을 도련으로 봅니다. BleedBox 가 없으면 0 입니다. 재단선 영역(MediaBox 여백)은 그림이 없는 영역이라 도련으로 치지 않습니다. 주문 bleed 보다 작으면 기존 BLEED_MISSING 경고가 그대로 나갑니다(파일 A).
5
합성·변환 크롭 정규화 — 임시 사본만 자르고 원본은 건드리지 않습니다.
  • 변환(도련 보정·내지 조판·쪽수 채움 — 작업 크기를 앎): 작업 크기에 정확히 맞춥니다. 파일 B·사방 4mm 파일 모두 212×299mm, 축소 인쇄(innerfit) 없음.
  • 합성·채움 — 주문 재단·도련을 아는 경로(10-03): editSessionId 가 있는 synthesize/external·편집기 내보내기, 도서 확정(도서 규격), compose 자동조립·관리자 합성, 첨부 쪽수 채움. API 가 contentTrim(재단·도련·허용오차)을 실어 보내고, TrimBox 가 주문 재단과 맞으면(±1mm) TrimBox + 사방 도련 으로 자릅니다. 도련은 템플릿셋 bleedMm(도서는 규격 bleedMm). 파일 A·B → 216×303(도련 3mm).
  • 합성 — 모르는 경로(editSessionId 없는 합성·compose 수동 경로·spread·내지 펼침면): 종전대로 BleedBox 가 명시돼 있고 그 밖에 사방 5mm 이상 균등한 재단선 영역이 있을 때만 TrimBox + min(선언 도련, 3mm) 로 자릅니다. 파일 A → 210×297, 파일 B → 216×303.
  • 이미 목표 크기면 자르지 않고, 목표가 MediaBox 밖이면 원본 박스를 유지합니다. 어느 경우든 TrimBox 는 페이지 중앙(±0.5pt)에 남아 인쇄소 재단 기준이 됩니다(Ghostscript 재증류 뒤에도 실측 확인).
  • 쪽수 채움 백지는 정규화된 페이지와 같은 좌표계로 만듭니다.
남은 한계: TrimBox 가 주문 재단과 1mm 넘게 다른 파일과 editSessionId 없는 합성은 위 모르는 경로를 따릅니다. 표지 TrimBox 판정·첨부 정리본 등록은 후속입니다.
6
안전장치 — 긴급 차단 플래그 WORKER_TRIMBOX_SIZE_CHECK: 코드 기본값 켜짐, false/0/off/no 로만 꺼짐. compose 에 ${WORKER_TRIMBOX_SIZE_CHECK:-true} 로 매핑해 .env 한 줄로 끌 수 있게 하고, 기동 로그 스냅샷에 실효값이 찍힙니다. 꺼지면 판정·정규화 모두 종전 동작이고, 10-03 부터는 합성 잡의 주문 재단·도련 적용도 함께 꺼집니다.
