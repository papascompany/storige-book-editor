코드에 있는 것

  • 표지 단위 = TemplateType.SPREAD 1장. 영역은 SpreadPlugin + computeLayout.
  • 책등 가변 = conversionMode: 'full' (기본). 내지 수·용지·제본으로 폭 재계산.
  • SKU 시드 = softcover_variable_spine (admin coverType, 고객 화면 0).
  • 페이지 네비 = SpreadPagePanel (표지 스프레드 + 내지 1,2,3…).
  • CoverFocusBar는 스프레드 모드에서 숨김 (EditorView !isSpreadMode). embed에는 없음.

Blurb / Canva 대비

  • Blurb는 표지를 “랩 한 장”으로 보여주고 책등 폭을 숫자로 알려 준다. Storige는 영역 가이드만.
  • Canva Print는 표지 목업이 먼저다. Storige는 바로 편집 캔버스.
  • 책등 경고(최소 페이지, 5mm 미만)가 콘솔로만 나감 — 고객 토스트 아님.

코드에 있는 것

  • flat-spine: 아트 3분할, 책등 가변은 허용(중심 고정).
  • 모드는 템플릿 JSON이지 상품 선택 화면이 아님. 고객은 가변/고정 차이를 모름.

Blurb 대비

  • Blurb의 “image wrap / printed wrap”은 주문 단계에서 고른다.
  • Storige는 운영자가 IDML을 어떻게 넣었는지로 결정. UX 이질감의 핵심은 선택지가 안 보임.

금박·형압

표지 템플릿에 페브릭을 배경으로 깔고 잠근다. 고객은 그 템플릿을 그대로 본다. 정적 이미지 치환이 아니다.

오너가 정한 계약 (2026-08-13)

  • 소재는 템플릿 제작 시 배경에 적용. 고객이 소재를 바꾸지 못함(잠금 맞음).
  • 고객은 소재가 입혀진 표지 템플릿 캔버스를 봐야 함. 미리보기 이미지로 캔버스를 대체하면 안 됨.
  • 후가공은 텍스트·PNG에 형압 / 금박 / 은박 정도. 템플릿 제작 시 관리자가 제공 여부를 고름.

지금 코드 (어긋난 부분)

  • coverEditable=false + LeatherCoverPreview = 캔버스 대신 정지 이미지, 인쇄 표지는 빈 PDF. 이 모델은 폐기. 컴포넌트 import 0건이라 고객 경로는 아직 일반 표지와 동일.
  • 배경 잠금 수단은 이미 있음: 객체 movable=false / LockPlugin / enabledMenus에서 BACKGROUND 제외.
  • 후가공 화면 효과: SpecialEffect 엠보싱·박(금)·컷팅. 은박 없음. 인쇄 별색 분판이 아니라 화면 필터.
  • enabledMenus는 TEXT/IMAGE 통째 온오프. “박만 허용” 같은 후가공 스위치는 없음.

코드에 있는 것

  • 타입 LEAFLET = 표지+내지 메타. 실제 편집은 editorMode=single이면 페이지 N장.
  • 네비 = BookNavigation (표지면 isCover 잠금 DnD). SpreadPagePanel 아님.
  • 출력만 갈림: pdfOutputMode single / duplex-merged / duplex-split. Admin 저장, 워커 적용. 편집기 캔버스는 동일.
  • 명함 조판은 워커 card-imposition. 편집기에 재단기 미리보기 없음.

Moo / Canva 대비

  • Moo는 상품이 먼저다. 명함이면 앞↔뒤 플립, 포스터면 1장.
  • Storige는 문서 편집기다. 단면/양면/다면이 출력 옵션이지 화면 메타포가 아님.
  • 다면 리플렛(3단 접지) 전용 접선·패널 가이드는 코드에 없음. 일반 페이지+블리드만.

한 줄 결론

인쇄 엔진은 업계 수준에 가깝다. 이질감은 이름 혼용이다. 표지펼침면=책등 고정(포토북HC·페브릭·기성). 표지3분할=뒷/등/앞, 책등만 가변. 내지펼침면은 상품이 고른다. 정본: docs/PRINT_TEMPLATE_GLOSSARY.md

제대로 된 것 (재구현 금지)

  • 책 모드 표지=펼침 1캔버스는 업계 정석이다. CoverFocusBar를 스프레드에서 끈 것도 맞다.
  • 내지 단면 + 표지만 스프레드(BOOK)는 Blurb softcover와 같다.
  • 포토북 내지 2-up(regionScope=inner)은 Mixbook/Blurb photo에 대응. 표지와 세션을 나눈 것은 구현 선택.
  • 출력 분리(cover.pdf + content.pdf)는 인쇄소 계약이지 UX 결함이 아니다.

이질감이 나는 이유 (우선순위)

  1. 상품 타입이 헤더/네비 카피에 안 나온다. “A4 기본 책자 430×297”만 보임.
  2. 페브릭 표지를 정지 이미지로 바꾸려 한 옛 G8 설계. 정본은 소재 배경이 깔린 템플릿 캔버스.
  3. 낱장에 앞·뒤·접지 문법이 없고 책과 같은 페이지 스트립.
  4. 책등 폭·고정/가변 상태가 사람 언어로 안 나옴 (콘솔 경고만).

오너가 이후에 지시할 내용

아래만 결정·지시하면 된다. 엔진 재작성은 지시하지 말 것.

A. 바로 지시해도 되는 것 (계약이 이미 섰음)

#지시 문장왜
A1 G8을 다시 연다. LeatherCoverPreview로 캔버스를 대체하지 마라. 표지 템플릿(소재 배경 포함)을 그대로 보여 주고, 배경·소재 객체만 고객 잠금. 오너 계약과 옛 설계가 반대. 컴포넌트 폐기 또는 관리자 썸네일 전용.
A2 템플릿 제작(admin iframe)에서 페브릭 소재를 배경으로 깔고 저장하는 절차를 운영 매뉴얼+잠금 플래그로 고정. 배경 잠금 API(movable / LockPlugin / BACKGROUND 메뉴 숨김)는 이미 있음.
A3 표지 후가공 허용을 템플릿셋 설정으로 둔다: 형압 / 금박 / 은박, 대상은 텍스트와 PNG. 기본은 전부 OFF. enabledMenus는 TEXT/IMAGE 통째라 너무 큼. 후가공 전용 플래그가 필요.

B. 지시하기 전에 한 줄만 정해 줄 것

#결정선택지
B1 후가공의 인쇄 의미 결정 2026-08-13: 화면 표시만. 별색/분판 PDF는 후속.
B2 은박 결정: 금박 경로 실버 팔레트 복제 (#C0C8D4). 별도 에셋 없음.
B3 컷팅 효과 결정: 페브릭 표지 UI에서 숨김. 형압·금·은만.
B4 coverEditable=false 의미 재정의 결정: 소재 배경 잠금 + 후가공. LeatherCoverPreview 캔버스 대체 폐기.

C. 지금은 지시하지 말 것

  • G8을 “미리보기 이미지 마운트”로 다시 열기 — 방금 폐기한 설계.
  • 면지 전용 페이지 전개 — 상품 0건, 이번 표지 계약과 무관.
  • 책등 엔진·낱장 조판 엔진 재작성.
  • 후가공을 새 캔버스 앱으로 분리.

복붙용 한 줄: “G8 재개. 페브릭 표지는 템플릿 캔버스를 보여 주고 소재 배경만 잠근다. 형압·금박·은박은 텍스트/PNG에만, 템플릿셋 설정으로 on/off. LeatherCoverPreview로 캔버스 대체 금지. 인쇄 별색은 B1 결정 후.”
