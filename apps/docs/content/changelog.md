# 변경 이력

파트너가 실제로 보내거나 받는 것이 달라진 변경만 날짜순(최신 우선)으로 적습니다.
내부 리팩터링·성능 개선은 포함하지 않습니다.

**계약 성장 규칙:** 에러 코드와 이벤트 카탈로그는 **추가만** 합니다. 기존 코드·이벤트명의
삭제나 의미 변경은 v1 안에서 일어나지 않습니다. 따라서 수신 코드는 **모르는 에러 코드와
모르는 이벤트를 관용**해야 합니다 — 그 전제로만 이 목록이 무해하게 자랍니다.

## 2026-07-28 — 파트너 문서 포털 발행

- 이 문서 사이트를 발행했습니다. 본문의 정본은 연동 가이드이며 포털은 발행 채널입니다.
- 연동 가이드에 **Partner API v1 표면을 등재**했습니다 — [1.7 v1 공통 계약](/guide/common/#1-7)(봉투·멱등·리밋·생성 유형·승격·최종화), [2.0 v1 도서 경로](/guide/self-editor/#2-0), [5.1 v1 엔드포인트 표](/reference/#5-1), [5.2 웹훅 발신 경로 2종](/reference/#5-2).
- [1.2 인증](/guide/common/#1-2) 에 v1 의 `Authorization: Bearer` / `X-API-Key` 병행 수용과 값 불일치 시 401 을 명시했습니다.
- 문서 정정: [2.4](/guide/self-editor/#2-4) 의 워커 파일크기 상한 표기가 `2 GB` 로 잘못 적혀 있었습니다 → **현재 프로덕션 배포값 1 GB** 로 정정. [1.4](/guide/common/#1-4)·[5.3](/reference/#5-3)·FAQ 의 서술이 정확한 쪽이었습니다.
- 문서 정정: [4.2 갭 표](/guide/type3/#4-2) 의 웹훅 서명 항목이 "HMAC 아님 / 시크릿은 no-op" 인 옛 상태로 남아 있었습니다 → 현재 발신 경로 2종을 반영했습니다.

## 2026-07-20 — 실행 예제 3종 공개

- 레포 `examples/` 에 최소 실행 예제가 추가됐습니다: PDF 업로드 주문 · 임베드 세션 승격 · 웹훅 수신.
- 각 예제는 라이브 키 없이 도는 오프라인 검증을 포함합니다. **실 서버 대상 스모크는 포함하지 않습니다** — 파트너 환경에서 별도로 확인하세요.

## 2026-07-16 — `/api/v1/books` 도서 표면 개시

- 도서 생성·목록·상세, 자산 투입(`pdf-cover` · `pdf-contents` · `photos`), 최종화 착수·폴링, 최종 PDF 다운로드가 열렸습니다. → [2.0](/guide/self-editor/#2-0)
- 임베드 완료 세션을 도서로 올리는 **`EDITOR_SESSION` 승격**이 동작합니다. 세션 산출 PDF 가 자동으로 연결되므로 수동 자산 투입이 필요 없습니다. → [1.7](/guide/common/#1-7)
- `GET /api/v1/books/{uid}/pdf` 는 v1 에서 **유일하게 봉투가 없는** 라우트입니다(성공 시 raw PDF 스트림). 수신측은 `Content-Type` 분기가 필요합니다. → [1.7](/guide/common/#1-7)
- 생성 유형 `TEMPLATE` · `MIX_COVER_TEMPLATE` 는 **미구현**이며 서버가 422 로 거부합니다.

## 2026-07-15 — Partner API v1 개시

- 공통 계약이 열렸습니다: 성공/에러 봉투, `Authorization: Bearer` 와 `X-API-Key` 병행 인증, `Idempotency-Key` 멱등(POST 한정, 24시간), API 키 단위 레이트리밋(general 300/min · heavy 100/min, 429 + `Retry-After`). → [1.7](/guide/common/#1-7)
- 판형 라우트 3종(`/api/v1/book-specs` 목록·상세·`calculated-size`)이 열렸습니다. `calculated-size` 는 페이지 수 기준으로 내지·표지 펼침면·책등의 실측 mm 를 돌려줍니다.
- **사이트별 웹훅 설정(v2)** 과 발송 이력 라우트 7종이 열렸습니다. 설정이 있는 사이트는 HMAC 전용 발신(`X-Storige-Signature-HMAC` + `X-Storige-Delivery`)으로 전환되고, 설정이 없으면 레거시 발신이 그대로 유지됩니다. → [5.2](/reference/#5-2)
- 구독 가능 이벤트에 `book.finalization.completed` / `.failed` 2종이 **추가**됐습니다(기존 7종은 그대로).

## 2026-07-13 — 편집기 도련 보정

- 편집기 업로드 흐름에 도련 자동 삽입 보정이 추가됐습니다(재단 사이즈 → 작업 사이즈, 콘텐츠 무스케일 중앙 배치, 원본 보존). 서버간 파트너 계약 표면은 변경되지 않았습니다.

## 2026-07-06 — 편집기 이벤트 1종 추가

- 임베드 편집기 발신 이벤트에 `editor.pricingChange` 가 **추가**됐습니다(가격 설정이 있는 템플릿셋 + 회원 세션 한정). 기존 이벤트의 payload 는 변경되지 않았습니다. → [3.2](/guide/embed/#3-2)

## 2026-07-03 — 썸네일 라우트 인증 전환

- `GET /api/files/{id}/thumbnail` 이 무인증에서 **API 키 + 테넌트 대조**로 바뀌었습니다. 키 없이 호출하던 통합은 헤더를 추가해야 합니다. → [5.1](/reference/#5-1)

## 2026-06-25 — 페이지수 검증 데이터 주도화 · 보정 엔드포인트

- `orderOptions` 에 `pageMultiple` · `pageCountMax` · `pageCountMin` 을 보내면 워커가 그 값으로 페이지수를 검증합니다. **셋 다 보내지 않으면 기존 동작 그대로**입니다(비파괴). → [2.4](/guide/self-editor/#2-4)
- 배수 위반으로 `FIXABLE` 판정된 PDF 에 빈 페이지를 추가하는 `POST /api/worker-jobs/fix-pagecount/external` 이 열렸습니다(비동기, 원본 보존, 새 `outputFileId` 반환). → [2.6](/guide/self-editor/#2-6)

## 2026-06-23 — 레거시 웹훅 HMAC 헤더 발신 정상화

- 전역 시크릿이 컨테이너에 주입되지 않아 레거시 경로의 HMAC 헤더가 **발신되지 않던** 문제를 수정했습니다. 이 헤더를 검증하도록 구현해 둔 수신측은 이 시점부터 실제로 헤더를 받습니다. → [5.2](/reference/#5-2)
