## 2. 계약 보장 (변경 없음)
- **postMessage 엔벨로프 v1 시맨틱 불변** — 이벤트/명령 추가·변경 0건. 동결 라우트 무접촉.
- **canvasData 직렬화 하위호환** — 신규 직렬화 속성 0건. C5 사본은 기존 복제(Ctrl+D) 파이프라인 재사용. 스냅 토글은 UI 설정(localStorage)일 뿐 저장물/PDF와 무관.
- **관리자 보호객체 규약 불변** — 위치고정/삭제잠금 객체는 C5 복제 대상 제외, 화살표 이동도 이동잠금 존중.
- 신규 기능은 전부 **additive + 기능 플래그**(문제 시 Storige 측 즉시 롤백, 재배포 필요).

## 3. 요청 사항 (회귀 확인 — 권장 30분 내외)
1. 기존 골든 시나리오 1회: 상품/세션 진입 → iframe 로드 → 편집(객체 추가·이동) → 저장 → 완료 콜백 정상 수신.

3. C6 모바일 롱프레스 동작 변경을 **QA·CS에 공유**(사용자 문의 대비).
4. 참고(의도된 동작): **빈 캔버스 영역** 롱프레스 시 '붙여넣기'만 있는 메뉴가 표시될 수 있음(데스크탑 우클릭과 동일). 오류 아님.
