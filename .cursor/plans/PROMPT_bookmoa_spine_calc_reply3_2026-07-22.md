- 골든 테스트 6케이스 추가(각 값·÷2 정합 ±0.002·19.2/16.1 라이브값). **이로써 모달↔서버 표기가 아르떼 무선에서 정합**.
- **주의(용어)**: 우리 모달 라벨은 `아르떼 130g`(공백+g, PERFECT_PAPERS 표기 관례). 서버는 별칭(`아르떼(UW/NW)130` 등)을 흡수하므로 무영향. 모달은 독립 계산기(주문 지종을 매핑하지 않고 사용자가 직접 선택)라 라벨 표기차가 서버 호출에 개입하지 않는다.

## 2. §3-1 — 우리 입장(재확인) + 대기

- 귀측이 **현행 3번**(spine 미해석 시 단일판형 SIZE_MISMATCH 발행)임을 인정하고, G3 게이팅 ON으로 **실차단**됨을 확인해 준 점 접수.
- 완화안(cover+무선/양장 spine 미해석 시 단일판형 SIZE 검증 스킵 + 비차단 경고 `SPINE_PARAMS_UNRESOLVED`)에 **동의**. 이 방향이 종전 무음 기간과 동일한 무해 동작이라 오픈 차단 사고를 막는다.
- **요청**: `SPINE_PARAMS_UNRESOLVED` 확정·배포 시 코드·details 형태를 통보해 달라. 우리 `PdfValidationModal`은 신규 code를 만나면 기본 표기로 폴백하나, 비차단 경고로 정확히 노출하려면 매핑을 추가하겠다(우리가 흡수). 현재 CODE_MAP: `SPINE_SIZE_MISMATCH`(error) 보유.

## 5. 잔여 미매핑 두께 — 오너 회신 (귀측 `paper_types` 시드 요청)

오너가 잔여 미매핑 지종의 **낱장 caliper(실측 ㎛)** 를 회신했다. 우리 모달(`spine-calc.js`)엔 편입 완료(양장=caliper mm/장, 무선=caliper÷2 mm/페이지). **귀측 서버 v2 `paper_types`에도 동일 시드를 요청**한다 — 안 그러면 fail-closed 재계산이 이 지종들에서 계속 404→SOFT 생략된다.

| 지종(우리 innerPaper) | caliper 실측 | 양장 mm/장 | 무선 mm/페이지 |
|---|---|---|---|
| 아르떼(UW/NW)90 | 약 110㎛ | 0.110 | 0.055 |
| 아르떼(UW/NW)105 | 약 155㎛ | 0.155 | 0.0775 |
| 아르떼(UW/NW)310 | 약 400㎛ | 0.400 | 0.200 |
| 모조220(백색) | 약 250㎛ | 0.250 | 0.125 |
| 모조260(백색) | 약 300㎛ | 0.300 | 0.150 |
| 뉴플러스(백색/미색)80 | 81±3㎛ | 0.081 | 0.0405 |
| 이라이트80 | 130±3㎛ | 0.130 | 0.065 |
| 드로잉220 | 320±5㎛ | 0.320 | 0.160 |
| 도화지170 | 268±5㎛ | 0.268 | 0.134 |

- 환산 규칙: **무선 per-page = caliper ÷ 2**(1장=2페이지, 정의상 정확 — 앞 아르떼 130~230의 1㎛ 출처차 없음). 양장 per-sheet = caliper 그대로. `±`는 측정공차 → 중앙값 채택.
- 뉴플러스 80g은 백색/미색 동일 caliper(81㎛) → 별칭 2건 동일값.
- **여전히 미회신(오너 확인 지속)**: 양장 모조120·뉴플러스100(백/미) / 무선 아트지80·250·300·스노우지80·250·300. 확보되는 대로 추가 회신.
- 라이브 실증(우리 모달): 무선 이라이트80 200p → 13.0mm(0.065×200) · 양장 이라이트80 200p → 17mm(합지4+내지13) · 콘솔0.
