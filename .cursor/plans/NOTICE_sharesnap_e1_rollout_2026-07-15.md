# [지시문] ShareSnap 세션 전달 — Storige 편집기 E1 롤아웃 공지 (2026-07-15)

> 용도: ShareSnap 연동 세션(또는 파트너 담당자)에 그대로 전달하는 자기완결 지시문.
> 발신: Storige CTO 오케스트레이션 세션. 시크릿 없음. ShareSnap은 현재 dev 연동 단계(도메인 미확정).

## 1. 무엇이 배포되었나 (2026-07-15, editor.papascompany.co.kr — iframe /embed 포함)
- **신규 편집 컨트롤 5종(기본 활성)**: 객체 간 스마트 정렬 가이드/스냅 + 회전 15° 스냅 / 이동·리사이즈·회전 실시간 mm·각도 피드백 / 선택 객체 플로팅 복제·삭제 바 / 재단 안전선 침범 시각 경고(임베드는 강조만, 토스트 없음).
- ⚠️ **DEL/Backspace 즉시 삭제 → 확인 모달** 변경(iframe 내부 UX — postMessage 계약 무관).
- **성능**: 배경제거 리소스(~111MB) eager 다운로드 제거 — 임베드 첫 로드가 가벼워짐(D1 사진주입·D2 핀치줌 플로우에 순수 수혜).

## 2. 계약 보장 (변경 없음)
- postMessage 엔벨로프 v1 시맨틱 불변, canvasData 하위호환(골든 PDF byte-identical 실증), 신규 기능 전부 additive+플래그(문제 시 storige측 off 롤백 — 전역 단위).
- shop-session JWT·사진 주입(D1)·핀치줌(D2) 경로 무접촉.

## 3. 요청 사항 (dev 환경 회귀 — 권장 20분 내외)
1. dev E2E 시나리오 1회: 사진 주입 → iframe 편집(사진틀 스왑·이동) → 저장 콜백 수신 정상.
2. 모바일 뷰포트에서 객체 선택 시 상단 액션 바 clamp(화면 밖 이탈 없음) 확인 — ShareSnap은 모바일 중심이라 특히 권장.
3. 회전 스냅: 터치 회전은 15° 배수 ±3°에서 스냅됨(그 외 자유각). 미세 각도(13° 등) 요구 UX가 있으면 회신 — 스냅 해제 토글 검토 항목으로 등재돼 있음.
4. 이상 발견 시 증상+세션 ID 회신.

## 4. 참고 — ShareSnap측 기존 잔여 액션 (이번 변경과 무관, 재리마인드)
