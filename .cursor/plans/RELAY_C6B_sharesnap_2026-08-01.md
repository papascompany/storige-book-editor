## 변경 사항 (3건 모두 ShareSnap 해당)

### 1. C6-b — 컨텍스트 메뉴 '삭제' 확인 모달 경유 ★모바일 체감 있음

- **이전**: 컨텍스트 메뉴(모바일 롱프레스 / 데스크탑 우클릭)의 '삭제'가 확인 없이 **즉시 삭제**.
- **이후**: '삭제' 선택 시 **삭제 확인 모달 1스텝 경유** — DEL 키 삭제와 동일한 안전 흐름으로 통일.
- **효과**: 모바일 오탭 삭제 방지(안전 강화 방향). **ShareSnap은 모바일 중심 서비스라 이 항목이 가장 체감될 변경**입니다 — 모바일 롱프레스 컨텍스트 메뉴(기배포)에서 '삭제'를 누르면 이제 확인 모달이 한 번 뜹니다.
- **추가 보완 (2026-08-01 배포)**: 모바일 컨텍스트 메뉴의 해제 동작 2건을 함께 손봤습니다 —
  ① 메뉴 밖 빈 곳을 탭하면 메뉴가 닫힙니다(종전에는 닫히지 않았습니다),
  ② 삭제 확인 모달이 열릴 때 메뉴가 자동으로 닫혀 모달 버튼을 가리지 않습니다.
  모바일 중심 서비스인 ShareSnap 에서 특히 체감되는 개선입니다.
- **Storige 측 검증 완료 (2026-08-01)**: iOS Safari(iPhone 17 Pro · iOS 26.5 시뮬레이터)에서 실제 터치
  입력으로 **롱프레스 → 컨텍스트 메뉴 → '삭제' → 확인 모달 → 취소** 전 구간을 확인했습니다.
  Android Chrome 은 동일 엔진 계열 자동 검증까지 완료했습니다.

### 2. C5 — Alt+드래그 복제 다중선택 확장 (경미)

- 기존 C5(단일 객체 Alt+드래그 복제)의 확장 — **다중선택 상태에서도 Alt+드래그로 선택 전체 복제**. 원본은 드래그되어 나가고 사본이 시작 위치에 잔류(Canva 동일 시맨틱).
- 데스크탑 한정(Alt 키). 모바일 무관.

### 3. D-E2-1 — 분배 단축키 (릴리스 노트 수준)
