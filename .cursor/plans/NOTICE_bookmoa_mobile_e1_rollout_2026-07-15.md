## 2. 계약 보장 (변경 없음)
- postMessage 엔벨로프 v1 시맨틱 **불변**(이벤트 9종·명령 3종). 동결 라우트 무접촉 — `contract-freeze.spec` + GUARDED spec CI green 상태로 배포됨.
- canvasData 직렬화 하위호환: 기존 세션 로드·재저장 왕복 무손실(골든 PDF 3케이스 byte-identical 실증).
- 신규 기능은 전부 additive+기능 플래그. 문제 발생 시 storige 측에서 플래그 off 롤백 가능(단, 플래그는 editor 배포 단위 전역 — 사이트별 개별 off는 현재 미지원).

## 3. 요청 사항 (회귀 확인 — 권장 30분 내외)
1. 기존 골든 시나리오 1회: 상품 진입 → iframe 로드 → 편집(객체 추가/이동) → 저장 → 완료 콜백 수신 정상.
2. 모바일 소형 뷰포트(375폭)에서: 객체 선택 시 상단 액션 바가 화면 밖으로 나가지 않는지, 저장/완료 버튼 가림 없는지.
3. DEL 키(외장 키보드/PC 웹) 삭제 시 확인 모달이 뜨는 변경을 QA·CS에 공유.
4. 이상 발견 시: 증상+세션 ID+뷰포트를 storige로 회신(플래그 off 롤백 판단).
