## 1. 오너 회신 — 잔여 미매핑 8종 caliper

reply3 §5의 미회신 8칸(양장 모조120·뉴플러스100 / 무선 아트지·스노우지 80·250·300)에 대한 오너 실측 caliper. 각 지종이 **정확히 각 표의 비어있던 칸**에 대응한다(양장에 없던 것 / 무선에 없던 것).

| 오너 회신 지종 | caliper | 편입 위치 | 값(mm) |
|---|---|---|---|
| 모조120(백색) | 약 140㎛ | **양장 신규** `백색모조120` | 0.140 (무선 백모조120은 기존 존재) |
| 뉴플러스100(백/미) | 101±3㎛ | **양장 신규** `뉴플러스백색100`·`뉴플러스미색100` | 0.101 (무선 뉴플러스100은 기존 존재) |
| 아트지80 | 64±3㎛ | **무선 신규** `아트지 80g` | 0.032 (÷2) — 양장 `아트80(무림)`=0.064 기존 |
| 아트지250 | 231~235㎛ | **무선 신규** `아트지 250g` | 0.1165 (중앙 233/2) — 양장 무림0.235/한국0.231 기존 |
| 아트지300 | 284~290㎛ | **무선 신규** `아트지 300g` | 0.1435 (중앙 287/2) — 양장 무림0.290/한국0.284 기존 |
| 스노우지80 | 약 71㎛ | **무선 신규** `스노우지 80g` | 0.0355 (÷2) — 양장 `스노우80(무림)`=0.071 기존 |
| 스노우지250 | 260±10㎛ | **무선 신규** `스노우지 250g` | 0.130 (÷2) — 양장 `스노우250(무림)`=0.260 기존 |
| 스노우지300 | 320±10㎛ | **무선 신규** `스노우지 300g` | 0.160 (÷2) — 양장 `스노우300(무림)`=0.320 기존 |

- 환산: 양장 per-sheet = caliper, 무선 per-page = caliper ÷ 2. ± 공차·범위는 중앙값.
- **미세 갱신 2건(고지)**: 무선 `백모조 120g`(0.069→**0.070**)·`뉴플러스100`(0.051→**0.0505**)을 오너 caliper 기준으로 갱신했다. 기존값은 youshindang 원본 추정치였고, 오너 실측(140/101㎛) 기준으로 통일해 **양장↔무선 ÷2 정합**을 확보(0.070×2=0.140, 0.0505×2=0.101). 차이 극미(200p에서 0.1~0.2mm).
- 아트지250/300은 우리 innerPaper가 산지(무림/한국) 구분 없는 단일 라벨이라 오너 범위의 **중앙값**을 채택.

## 3. 귀측 서버 시드 요청 (마지막 배치)

reply4 §5 시드(10항목)에 이어, **아래 잔여를 `paper_types`에 시드**하면 fail-closed 재계산의 404/v1 폴백이 종결된다:

| 지종(별칭 흡수) | 양장 mm/장 | 무선 mm/페이지 |
|---|---|---|
| 백색모조120 | 0.140 | 0.070 |
| 뉴플러스(백/미)100 | 0.101 | 0.0505 |
| 아트지80 | 0.064 | 0.032 |
| 아트지250 | 0.233(중앙) | 0.1165 |
| 아트지300 | 0.287(중앙) | 0.1435 |
| 스노우지80 | 0.071 | 0.0355 |
| 스노우지250 | 0.260 | 0.130 |
| 스노우지300 | 0.320 | 0.160 |

- 뉴플러스100 무선(0.0505)·아트지250(0.1165)·아트지300(0.1435)은 소수 4자리 — 귀측 DECIMAL(7,4) 컬럼(reply4 §1)이라 반올림 없이 저장 가능.
- 아트지/스노우지는 귀측 서버가 산지(무림/한국)를 어떻게 다루는지에 따라 무선값이 우리 중앙값과 미세 다를 수 있다 — 시드 후 `[spine-inject]` 로그로 대조하자(오차 2단계 승격 전 대조 지표에 포함).
